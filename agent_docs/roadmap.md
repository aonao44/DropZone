# DropZone 開発ロードマップ

## 概要

本ドキュメントは、素材管理・検品 SaaS「DropZone」の実装順序とタスクリストを定義します。
**requirements_v02.md** に基づき、「提出」→「検品（OK/NG）」→「納品」のステータス管理に特化した「デジタル検品所」を構築します。

## リスク & 回避策

- **検品UIの複雑化** → コンポーネント分割、段階的リリース
- **メール到達率** → Resend のレピュテーション管理、SPF/DKIM設定
- **課金トラブル** → Stripe Customer Portal で自己解決を促進
- **ストレージ肥大** → Free は7日で物理削除、Proは30日後アーカイブ
